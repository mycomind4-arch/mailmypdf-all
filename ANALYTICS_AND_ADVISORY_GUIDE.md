# Admin Chat Agent: Analytics & Advisory Features

**Your AI-Powered Platform Intelligence & Execution Engine**

---

## Overview

The Admin Chat Agent now combines two powerful capabilities:

1. **Command Execution** — Make real-time changes to workflows, verticals, and landing pages
2. **Analytics & Advisory** — Get intelligent insights about your platform performance and actionable recommendations

This creates a unified interface where you can:
- Ask about performance metrics
- Get improvement suggestions
- Execute changes based on those insights
- All in natural language conversation

## Privacy & Security

### What Data the Agent Sees

- Aggregated metrics only (no PII)
- Conversion rates, completion times
- User counts per segment
- Revenue metrics
- Workflow performance

### What the Agent Cannot See

- User names or emails
- Specific case details
- Financial transactions
- API keys or credentials

### Audit Trail

Every query is logged:
- What you asked
- When you asked it
- What data was accessed
- What actions were recommended/executed

### 1. Be Specific

❌ "What's wrong?"  
✅ "Why is housing mail conversion only 35%?"
