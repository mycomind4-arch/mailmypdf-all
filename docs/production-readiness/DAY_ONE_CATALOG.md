# Day-One Catalog

## Publicly purchasable

None until the security and money-flow gates pass.

## First limited-beta candidate after gates

- MailMyPDF Core: mail-a-pdf only, one verified direct-PDF mailing path.
- CP2000 only after approval affordance, mail route, and deployed provider certification close.

## Hidden

All other Core utility profiles; all Notice Respond except certified CP2000; all Dispute Mail except certified Credit Report; all Appeal Mail until individually certified; and all Immigration, Small Business, GovReply, Tenant, Permit, Insurance, Benefits, Private Office, Records, and Code Enforcement profiles until their specific gates pass.

Availability must require zero-blocker certification and a recent deployed smoke-test record. Registry live status and pricing production status are not sufficient.
