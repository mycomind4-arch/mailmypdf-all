# E2E Certification Plan

A workflow earns Tier 1 only when run against the deployed build with safe payment/provider environments and retained evidence:

1. Create an authenticated account and owner-bound workflow ID.
2. Upload realistic, malformed, oversized, wrong-MIME, and malicious-file fixtures.
3. Confirm durable persistence, close the browser, and resume.
4. Analyze with source provenance, model/prompt/version, schema validation, timeout, and retry evidence.
5. Add evidence and verify ownership and required/optional rules.
6. Generate, edit, version, and regenerate a draft.
7. Change facts and verify approval/readiness invalidates.
8. Review recipient, content, evidence, deadline, assumptions, and warnings.
9. Approve explicitly; record actor, timestamp, version, and hash.
10. Request a server quote and reject altered client totals.
11. Repeat checkout and provider requests; verify idempotency.
12. Pay in test mode; verify only a signed webhook changes paid state.
13. Create mailing intent from the paid approved artifact.
14. Persist provider acceptance, ID, status, errors, tracking, and proof callbacks.
15. Verify history, receipt, tracking, proof, refund, outage recovery, webhook replay, and duplicate protection.
16. Attempt cross-account access and artifact substitution; expect denial.
17. Retain deployment SHA, config version, logs, screenshots, and operator signoff.
