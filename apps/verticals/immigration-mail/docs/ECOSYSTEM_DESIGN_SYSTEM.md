# Immigration Mail — Ecosystem Design System

Immigration Mail is a flagship MailMyPDF vertical and should consume the shared visual contract from `@mailmypdf/design-system`.

## Shared

Use the ecosystem typography, spacing, radius, neutral surfaces, status semantics, focus treatment, responsive layout and workflow/approval patterns.

## Immigration theme

Use the violet accent as the vertical identity layer. Keep the rest of the UI family-consistent with MailMyPDF.

## Domain-specific UI

Immigration-specific case timelines, document checklists, multilingual controls, agency/source panels, deadline explanations, and guided workflows may be specialized. Their visual primitives should remain ecosystem-consistent.

## Required states

Use the shared vocabulary for Verified, Unverified, Needs Review, Missing Information, Deadline Risk, Approval Required, Sent, Tracking, and Proof Available.

## Accessibility

Target WCAG 2.2 AA, preserve visible keyboard focus, never encode meaning through color alone, and support reduced motion.
