# Benefits Appeal — Canonical SEO Site Structure

Preserve the existing ecosystem-wide navigation exactly. This is the SEO/content hierarchy beneath that shell.

## Public
- `/` — Benefits Appeal pillar: appeal denied, reduced, suspended, or terminated benefits; explain the problem plainly; show how AI handles the heavy lifting; feature the most-used workflows; clear review-before-send CTA.
- `/workflows` — scalable workflow discovery hub with search, suggested searches, category browsing, and premium workflow cards using a consistent image area.
- Individual workflow authority pages — one page per search intent, with unique explanation, what to gather, how AI helps, what the user reviews, FAQ, related workflows, and a direct handoff to the interactive workflow.
- `/how-it-works` — upload decision → AI understands → organize facts/evidence → build appeal → review/approve → MailMyPDF sends → track/preserve proof.
- `/products`, `/pricing`, `/mail-a-pdf` — ecosystem/product pages.
- `/about`, `/contact`, `/faq`, `/resources/*` — supporting SEO/footer content.
- `/privacy`, `/terms`, `/404` — legal/error.

## Workflow taxonomy
Social Security & disability; unemployment; Medicaid & health benefits; public assistance; veterans benefits; general benefits.

## Discovery standard
The hub is search-first as the catalog grows. Users should be able to search by situation, document, program, agency, or outcome without knowing the workflow's exact name. The homepage may feature 4–8 high-value workflows, but `/workflows` remains the complete directory.

## Workflow card standard
Every workflow card uses the ecosystem card anatomy: top image placeholder, category, strong serif title, concise problem-focused description, search-intent context, and clear CTA. Relevant assets can replace the placeholder later without changing layout.

## SEO flow
Pillar → workflow hub → authority page → authenticated workflow. Existing workflow URLs remain canonical unless a deliberate, tested redirect/canonical strategy is introduced.

## Application routes
Auth, dashboard, account, analysis and authenticated workflow routes remain functional but are not primary SEO navigation.

## Simplicity rule
Keep the visible workflow small. AI handles decision analysis, facts/evidence, deadlines, issue identification, appeal grounds, strategy, drafting and validation underneath. The user reviews and approves the exact response.

## Navigation and typography lock
Do not add vertical-specific menu items. Use the existing MailMyPDF ecosystem shell and the shared ecosystem typography hierarchy.
