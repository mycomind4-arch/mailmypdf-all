# Records Requests SEO Keyword Map

Research basis: Keyword.com US English keyword discovery, August 2026.

## Strategy

Records Requests has a very large search universe. The best structure is **record type + request method + jurisdiction/context**, with public-records education feeding into a request workflow.

## Priority clusters

- open records request — 1,900/mo
- public information request — 590/mo

### Court / government records
- how can I get court records — 1,900/mo
- how to get court records — 590/mo
- military records request — 1,900/mo
- OPRA request — 1,600/mo
- FOI request — 1,300/mo

### Vital / specialized records
Birth, marriage, death, criminal-history and other records have large volumes but frequently have transactional government portals. Use them where the product can add value through request preparation, tracking, fulfillment review, or escalation.

## Recommended architecture

Records Requests
├── Public records / FOIA
├── Police records
├── Court records
├── Property / permit / code records
├── Criminal-history records
├── Military records
├── Vital records
└── Request follow-up / incomplete production

## Rule

Avoid competing with direct government portals on pure "download a form" intent. Focus pages on preparing, tracking, auditing, and following up on requests.
