# Insurance Claims — Master Workflow Directory

This repository is the master product for insurance-claim correspondence and dispute workflows.

Initial workflow families:
- claim documentation
- request for additional information
- denied claim response
- underpayment dispute
- property damage claim
- coverage/correspondence review
- claim appeal

Each workflow should have distinct search intent, source documents, evidence needs, response structure, and canonical content when warranted. Shared identity, documents, mailing, proof, billing, and UI belong to the platform layer.
