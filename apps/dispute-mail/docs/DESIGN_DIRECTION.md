# Dispute Mail — Product Design Direction

## Role in the MailMyPDF family

Dispute Mail is the consumer dispute-correspondence specialist. It turns an identified error into a supported dispute, then into documented physical mail.

Primary journey:

**Identify Error → Gather Evidence → Prepare → Review → Mail → Track → Prove**

## Design benchmark

Use Notice Respond as the family-quality benchmark and Appeal Mail as the deeper analysis reference. Preserve Dispute Mail's stronger teal/rose identity rather than flattening it into a clone.

## Product personality

Direct, confident, protective, practical. The experience should communicate: "We help you make the dispute clear and keep the record."

## Visual language

- Deep teal/navy foundation
- Warm paper/cream surfaces
- Restrained rose/red accent for disputes and actions
- Serif headlines, compact sans body text, monospace metadata
- Document cards, evidence chips, mailing/proof badges
- Avoid generic chatbot aesthetics

## Homepage

Lead with the error/dispute problem. Show the complete path from identifying the problem through proof of submission. Workflow cards should be the primary discovery mechanism.

## Workflow pages

Each dispute type gets distinct content covering:

- what can be disputed
- useful documents
- what the workflow asks for
- evidence to attach
- deadline considerations where supported
- what the letter can contain
- review requirements
- MailMyPDF mailing/proof path

Do not fabricate legal rights, deadlines, outcomes, testimonials, or successful dispute results.

## Workspace

Use a compact case view with:

**Issue → Facts → Evidence → Draft → Validation → Mail → Proof**

Keep source documents accessible while reviewing claims.

## Trust

Emphasize user control, source-grounded drafting, explicit approval before mailing, tracking, and retained proof.

## Responsive/accessibility

Use the existing responsive component patterns. Mobile must retain the issue/evidence/draft hierarchy without requiring horizontal scrolling. Status must never rely only on color.

## Definition of done

The site should look like a premium specialized correspondence product and make the physical-mail/proof advantage obvious within the first screen.
