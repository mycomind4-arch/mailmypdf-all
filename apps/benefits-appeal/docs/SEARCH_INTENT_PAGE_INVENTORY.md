## SEO rules
“Sample” and “template” searches should be satisfied with useful examples embedded in the canonical intent page, then converted into the guided workflow. Do not publish thin template permutations.

## Conversion path
Search → decision/appeal type → upload decision + evidence → identify grounds → build appeal → review → proof-ready mailing → track outcome.
