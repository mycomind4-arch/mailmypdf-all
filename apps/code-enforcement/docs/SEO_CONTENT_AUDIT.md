## Verdict
**The current root is a command-center prototype, not an acquisition page. Replace the public root with a search-intent landing page and move the command center to `/dashboard`.**

## Product journey

Notice → Property/parcel → Violations → Evidence → Timeline → Deadlines → Procedural analysis → Response/appeal → Records request → Mail/proof.

The public page should make this journey obvious and offer **Upload your notice** as the primary CTA.

## Content safeguards

Do not call a procedural discrepancy a legal violation. Distinguish fact, inference, unknown, rule, and recommendation. Jurisdiction-specific ordinances and deadlines must be sourced and versioned.
