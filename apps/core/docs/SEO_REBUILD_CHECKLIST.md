# SEO Rebuild Checklist

This checklist is the acceptance gate for the MailMyPDF SEO/content rebuild.

## Master brand
- [x] MailMyPDF is the customer-facing master brand.
- [x] Solutions page no longer presents BureaucracyOS as the consumer-facing umbrella.
- [x] Solution discovery starts from user situations rather than product-name knowledge.
- [ ] Homepage hero reduced to one primary action plus one clearly secondary path.
- [ ] Privacy/security trust signals moved into the primary conversion path.
- [ ] Pricing calculator/estimator makes page count and mailing add-ons explicit before checkout.
- [ ] Synthetic dashboard examples replaced with clearly illustrative product previews.
- [ ] Production domain replaces preview URL everywhere in deployment/metadata.

## Search architecture
- [x] Transactional mailing intent belongs to MailMyPDF.
- [x] Situation/problem intent belongs to specialized solution workflows.
- [x] Live vertical SEO metadata is indexable; preview/soon workflows are noindex.
- [x] Important-document intent page added.
- [x] Government-notice intent page added.
- [x] Canonical solution index added to sitemap.
- [ ] Audit existing intent pages for cannibalization before adding more.
- [ ] Add unique internal-link paths from each vertical to the mailing workflow.

## Content quality
- [ ] Every indexed page has a distinct intent.
- [ ] No page exists solely as a keyword permutation.
- [ ] Situation pages explain the user's problem before describing product features.
- [ ] Claims about legal/administrative outcomes are avoided.
- [ ] Pricing and trust claims match the actual product behavior.

## Vertical audit
- [ ] Appeal workflow
- [ ] Notice response
- [ ] Records requests
- [ ] Code enforcement
- [ ] Disputes
- [ ] Immigration
- [ ] Tenant/landlord
- [ ] Benefits appeals
- [ ] Claims
- [ ] Permit correspondence

The goal is not maximum URL count. The goal is maximum useful coverage with minimal cannibalization and a clear path from search intent to successful document delivery.
