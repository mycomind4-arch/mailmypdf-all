# Immigration Mail — Search-Intent Page & Workflow Inventory

## Architecture
Immigration Mail is the master vertical for understanding and responding to USCIS/immigration notices, requests, denials, rejections, appointments, and procedural correspondence. High-volume notice-identification searches should lead into specific action workflows.

## Tier 3 — Workflow pages
- Explain an I-797/I-797C notice
- Analyze a USCIS RFE
- Build an RFE response package
- Respond to a rejection notice
- Respond to a denial notice
- Prepare for a biometrics appointment
- Prepare for an interview notice
- Analyze Notice to Appear correspondence
- Organize evidence and supporting exhibits
- Prepare proof-ready mailing packet

## SEO rules
High-volume terms such as “I-797” are primarily informational. The page must answer what the document is and what it means before presenting the relevant action workflow. Avoid thin pages for punctuation/spacing variants of form names.

## Conversion path
Search → identify notice → explain meaning → determine required action → gather evidence → build response → review → proof-ready mailing → track.
