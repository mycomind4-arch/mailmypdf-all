# Immigration Mail Site Design

## Position

Immigration Mail is the document-and-correspondence product for immigration-related notices, requests, evidence packets, and responses.

Primary message: **Understand what was requested. Organize the record. Prepare the response. Mail it with proof.**

## Visual direction

Use the Notice Respond quality bar but give Immigration Mail a calmer case-packet identity. The interface should feel organized and reassuring without implying guaranteed immigration outcomes.

Tone: careful, organized, reassuring, procedural.

## Homepage

1. Hero focused on receiving an immigration notice/request and knowing what to do next.
2. Workflow strip: Understand Request → Organize Documents → Identify Gaps → Prepare → Review → Mail → Track → Prove.
3. Workflow directory for verified immigration correspondence types.
4. Document packet visualization showing notice, supporting evidence, forms, correspondence, and chronology.
5. Analysis capabilities: request extraction, document matching, missing-item detection, chronology, and response preparation where actually implemented.
6. Trust/safety section emphasizing source-grounded output and user review.
7. MailMyPDF fulfillment bridge.
8. FAQ and clear non-legal-advice language.
9. Ecosystem footer.

## Workflow pages

Every workflow page should include:

- notice/request type
- who it applies to
- useful documents
- requested information
- document/evidence organization
- missing or conflicting information
- response structure
- review requirements
- mailing path

Never imply that an immigration filing or response is guaranteed to succeed.

## Application shell

Use:

Request → Documents → Timeline → Gaps → Response → Review → Mail → Proof

Make document provenance and missing information obvious.

## Safety

Separate extracted facts, user-provided facts, inference, and unresolved questions. Never fabricate forms, facts, dates, legal conclusions, or filing outcomes.

## MailMyPDF

Use the final reviewed correspondence as the handoff artifact. Clearly show when the document is ready for physical mailing and preserve fulfillment status when the real integration is available.
